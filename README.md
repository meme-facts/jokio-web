# MemeVerse — Dark Themed Social Network UI

A dependency-free, responsive SPA for a meme-sharing social network. Built with semantic HTML, modern CSS, and vanilla JS.

## Features
- Dark navy background (#0d1117) with vibrant purple accents (#a855f7) and light purple highlights (#c084fc)
- Left vertical navigation bar with icons (Home, Create Post, Explore, Notifications, Messages, Profile, Settings)
- Central feed with animated, elegant card layout for memes/images/text
- Right profile panel with avatar, name, handle, followers, following, likes, dislikes, and Edit Profile
- Modals for Create Post and Edit Profile
- Rounded buttons, modern typography, smooth hover and page transitions
- Mobile responsive with collapsible sidebar
- Explore view with search and sort (Newest, Top, Trending)
- LocalStorage persistence for posts and profile

## Run
Open `index.html` directly in your browser or serve the folder (recommended for clipboard APIs):

```bash
# from project root
python3 -m http.server 5173
# then open http://localhost:5173
```
